# Judging criteria

Last updated: 2026-11-15.

How projects are scored, and where in this project a judge can find the answer to each question. This file points to evidence; it does not argue a case.

Sources:

- The global criteria: the Judging and Awards guide, https://www.spaceappschallenge.org/resources/judging-awards-guide/ , read on 2026-11-14, kept in [research/space-apps-guides/judging-guide.md](../../research/space-apps-guides/judging-guide.md).
- The questions under each criterion: the "Judging Criteria" slide shown by the Beirut organizers, photographed on 2026-11-14.

Each criterion is scored from 1 to 5 at every level of judging. The guide gives no weights.

## 1. Impact

How significant could this project be?

| Question | Where it is answered |
| --- | --- |
| What problem does it solve? | [product/overview.md](../product/overview.md), "The problem" |
| Who or what could benefit from it? | [product/overview.md](../product/overview.md), "Who it is for" |
| Could it advance science or technology on Earth or in space? | The replanning use case for missions whose dates slip; the teaching use |

## 2. Creativity

How original or innovative is the project?

| Question | Where it is answered |
| --- | --- |
| Does it offer a new or clever solution? | One screen that joins position data and terrain; 3D scenes lit by the real Sun |
| Does it improve existing ideas or technologies? | It builds on Quickmap, Moon Trek and JPL Horizons and removes the manual step of combining them |
| Does it approach the problem in an inventive way? | The horizon profile shared by the picture and the numbers; an assistant that can run the calculation |

## 3. Validity

Is the project scientifically and technically reliable?

| Question | Where it is answered |
| --- | --- |
| Is it based on established scientific principles? | [science/](../science/conventions-and-ephemeris.md): JPL ephemerides, LOLA terrain, a stated visibility rule |
| Has it been tested or supported by evidence? | [VALIDATION.md](../VALIDATION.md) and [science/validation.md](../science/validation.md): comparison with JPL Horizons and with NASA's illumination maps; the accuracy page in the app (https://moonmaps.vercel.app/accuracy) |
| Is it technically feasible and effective? | The running app, https://moonmaps.vercel.app; [architecture/system-overview.md](../architecture/system-overview.md) |

## 4. Relevance

Does the project address the challenge and use relevant resources effectively?

| Question | Where it is answered |
| --- | --- |
| Does it directly address the assigned challenge? | [product/challenge-coverage.md](../product/challenge-coverage.md), which maps every objective on the challenge page |
| Is NASA data used meaningfully in the solution? | [data/sources.md](../data/sources.md): every number and every surface comes from NASA data |
| If AI is used, does it meaningfully support the project's goals? | [backend/assistant.md](../backend/assistant.md): the assistant explains results and runs comparisons, and never produces a number itself; [reference/ai-use.md](../reference/ai-use.md) |

## 5. Presentation

How clearly does the team communicate its work?

| Question | Where it is answered |
| --- | --- |
| Are the problem and the proposed solution explained clearly? | The landing page; the idea description; the presentation |
| Does the team demonstrate how the project works? | The live app, https://moonmaps.vercel.app; the 30-second and 2-minute videos |
| Can the team explain its methods and results? | [science/](../science/visibility-and-metrics.md) and the accuracy page; every team member should be able to explain the visibility rule in one sentence |

## The path after the hackathon

Source: the Judging and Awards guide.

1. Local judges in Beirut choose the Global Nominees, announced 3 December 2026.
2. Global judges choose the Global Finalists and Honorable Mentions, announced 17 December 2026.
3. NASA and partner agency executives choose the ten Global Winners, announced 26 January 2027.
